# Папка скачанного

Сюда браузер кладёт всё, что скачал во время работы агента: файлы, картинки,
экспорт с сайтов. Путь перекрывается переменной `BU_MCP_DOWNLOAD_DIR`.

Содержимое папки в git не попадает — это рабочие файлы, а не код.

Проверить, что скачивание действительно дошло до файла, можно чекпоинтом:
`checkpoint(download=true)` или `checkpoint(download=".png")` — он ждёт, пока в
этой папке появится новый файл, и падает, если не появился.
